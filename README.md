# Полка

Первая версия площадки, где авторы смогут публиковать творческие работы, а посетители — покупать их.

На этом этапе готов адаптивный лендинг на чистых HTML, CSS и JavaScript: витрина с шестью демонстрационными работами, фильтры категорий, информационные окна и блок для авторов. Иллюстрации созданы средствами CSS, внешние библиотеки, шрифты и сервисы не используются.

**Это демонстрационный сайт:** авторы, работы и цены вымышлены. Регистрация, публикация, скачивание и оплата пока не реализованы. Данные посетителей не собираются.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для локального HTTP-сервера из папки проекта:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Файлы

- `index.html` — содержание и структура страницы.
- `styles.css` — адаптивные стили и иллюстрации.
- `script.js` — фильтры и информационные окна.
- `assets/favicon.svg` — иконка сайта.

## Публикация

GitHub Pages: ветка `main`, каталог `/ (root)`, без сборки. Файл `.nojekyll` отключает обработку Jekyll.
