# Полка

Первая версия площадки, где авторы смогут публиковать творческие работы, а посетители — покупать их.

На этом этапе готов адаптивный лендинг на чистых HTML, CSS и JavaScript: витрина с шестью демонстрационными работами, фильтры категорий, информационные окна и блок для авторов. Иллюстрации созданы средствами CSS, внешние библиотеки, шрифты и сервисы не используются.

**Это демонстрационный сайт:** авторы, работы и цены вымышлены. Вход и регистрация работают локально в браузере. Публикация, скачивание и оплата пока не реализованы.

## Тестовые аккаунты

- Администратор: логин `admin`, пароль `admin`.
- Пользователь: логин `user`, пароль `user`.

На странице `auth.html` можно войти, зарегистрироваться и выйти из аккаунта. Новые аккаунты и состояние входа хранятся в `localStorage` текущего браузера. Сервер и SQL-база не используются; данные между устройствами не синхронизируются. Пароли тестовых аккаунтов указаны прямо в `auth.js`, пароли новых аккаунтов сохраняются локально открытым текстом. Проверок регистрации нет, включая проверки сложности пароля и уникальности логина. Для учебного прототипа используйте только тестовые данные. Роль отображается в аккаунте и пока не открывает дополнительных функций.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для локального HTTP-сервера из папки проекта:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Файлы

- `index.html` — содержание и структура страницы.
- `styles.css` — адаптивные стили и иллюстрации.
- `script.js` — фильтры и информационные окна.
- `auth.html` — страница входа, регистрации и аккаунта.
- `auth.js` — тестовые пользователи, регистрация и состояние входа.
- `assets/favicon.svg` — иконка сайта.

## Публикация

GitHub Pages: ветка `main`, каталог `/ (root)`, без сборки. Файл `.nojekyll` отключает обработку Jekyll.
